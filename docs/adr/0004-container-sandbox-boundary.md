# ADR-0004：采用有限威胁模型的容器沙箱

- 状态：Accepted
- 日期：2026-08-05

## 背景

CodeRCA 需要运行测试、临时修改代码和验证补丁，但容器本身不能被宣传为对恶意代码的完整安全边界。

## 决策

容器沙箱只承诺防止正常测试的意外破坏，并隔离不受信任但非刻意恶意的开源仓库。运行采用预构建锁定镜像、非 root 用户、禁网、只读基础镜像、临时工作区及 CPU/内存/时间限制。

Agent 只能运行预注册命令，不能访问隐藏测试、宿主凭证或任意宿主路径。

## 替代方案

- 直接在宿主运行：实现简单，但副作用和凭证风险不可接受。
- 宣称生产级容器隔离：缺少内核、系统调用和多租户安全投入支撑。
- 微虚拟机：隔离更强，但明显超出 MVP 时间预算。

## 后果

- 正面：能够安全地覆盖主要开发与演示场景，安全声明与证据一致。
- 负面：不能运行恶意代码或提供公网多租户服务；镜像预构建增加数据集准备成本。
