# ADR-0003：统一检索接口并隔离检索消融

- 状态：Accepted
- 日期：2026-08-05

## 背景

项目需要展示 BM25、向量检索、混合检索和 reranker，但如果 Agent 自由选择底层算法，端到端结果会混合检索器差异与 Agent 决策差异。

## 决策

Agent 只调用统一的 `search_code`。底层检索配置由实验清单冻结，对 Agent 不可见。

检索层使用相同的标准查询，独立比较四种配置的 `Recall@K` 与 `MRR`；端到端评测只使用验证集选出的单一配置。

代码块以 AST 语义单元为主，超长块再分窗。核心命中只按根因符号计算，相关上下游代码作为辅助覆盖率。

## 替代方案

- 暴露多个检索工具给 Agent：能展示动态选择，但无法进行干净的检索消融。
- 只用混合检索：实现简单，但无法证明各组件的增益。
- 固定 Token 切块：通用但丢失代码符号边界。

## 后果

- 正面：RAG 能力有独立、可重复的实验依据；Agent 接口保持稳定。
- 负面：第一版不评估 Agent 自主选择检索算法的能力；需要维护离线检索基准。
