# ADR-0001：使用自研显式诊断状态机

- 状态：Accepted
- 日期：2026-08-05

## 背景

CodeRCA 的主要招聘信号之一是 Agent 工作流设计。默认 ReAct 循环难以清楚表达假设竞争、证据方向、实验语义、预算和停止条件，也难以稳定回放与评测。

## 决策

实现轻量、类型明确的诊断状态机。模型负责提出假设和选择实验；程序负责状态转移、Schema、权限、预算、错误与停止策略。

核心循环是：

```text
形成假设 → 选择实验 → 执行工具 → 更新证据 → 支持、拒绝或继续
```

最多保留三个活跃假设，状态限定为 `proposed`、`testing`、`supported`、`rejected` 和 `inconclusive`。

## 替代方案

- 使用 Agent 框架的默认 ReAct：实现快，但核心行为隐式且难以证明。
- 图工作流框架：可表达状态，但两周 MVP 会增加框架学习和适配成本。
- 完全由模型自由控制：缺少安全边界、终止保证和可重复性。

## 后果

- 正面：运行可审计、可回放、可构造确定性测试，面试中能够解释关键不变量。
- 负面：需要自行实现调度、状态持久化和失败恢复；模型灵活性受 Schema 约束。
