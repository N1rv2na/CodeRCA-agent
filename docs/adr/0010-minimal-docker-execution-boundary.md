# ADR-0010：两周 MVP 采用最小 Docker 执行边界

- 状态：Accepted
- 日期：2026-08-06
- 取代：ADR-0004

## 背景

CodeRCA 必须真实运行测试和候选补丁，但完整验证非 root、只读根文件系统、CPU/内存配额和跨平台行为会扩大两周 MVP 的调试面。直接在宿主运行又无法合理隔离正常测试的意外副作用。

## 决策

MVP 只支持一个预构建 Django 镜像和临时工作区，默认禁网，只执行注册命令，设置统一超时，并且不挂载模型凭证。模型服务留在容器外。完整资源限制矩阵、只读根文件系统、跨平台兼容和恶意代码防御延期。

## 后果

Docker Experiment 可以提供真实执行证据，但安全声明必须限定为降低正常测试的意外副作用，不能宣传为生产级沙箱或恶意代码边界。
